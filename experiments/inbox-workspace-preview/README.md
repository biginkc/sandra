# Synthetic Inbox presentation preview

This localhost preview imports the real reusable application component from
`src/components/inbox-workspace`. It uses 80 synthetic records and local React
state. Action clicks/drops report the selected IDs to the same callback but never
submit an operation. There is no database, provider, sync, authentication, or read
acknowledgment integration. The original user prototype is not changed.

After installing the repository's locked dependencies:

```sh
node experiments/inbox-workspace-preview/server.mjs
```

Open `http://127.0.0.1:58791/`. The server binds loopback, serves only three exact
assets, and provides no proxy or mutation endpoint. Rebuild/restart after source
changes. The CSS bundle is generated by esbuild from the actual component module.
Stop only the process started by this command; do not kill another local server.

Repeatable headless interaction checks:

```sh
node experiments/inbox-workspace-preview/verify.mjs
```

The browser must already be installed for the repository's Playwright version.
Checks exercise real DOM pointer/keyboard controls and the real TanStack virtual
list; virtualization is not mocked. `evidence.json` and screenshots are generated
only after their checks pass. Failed command logs should be retained separately.
Headless checks are not evidence of human feel or production latency. A final
human review, live adapters, complete accessible modal behavior, and production
workload testing remain separate acceptance work. The preview's selection review
is temporary demonstration code, not the production review-selection workflow.
