## 9. Critical learnings

- **BSD sed doesn't expand `\1` backreferences** the same as GNU sed. Use Python `re.sub` for multi-file in-place regex replacements on macOS.
- **React 19 ref-as-prop:** Function components accept `ref` as a regular prop, but TypeScript types still require `React.RefAttributes<T>` to be explicitly added to the interface. Adding it to `SearchInputPill` was necessary; same pattern will apply to any other copied registry components that need a `ref`.
- **GSD workflow advisory hook** fires on every direct file edit outside of `/gsd-*` commands. When executing pre-approved `autonomous: true` plans directly, the hook is advisory-only — safe to proceed.
- **`@theme inline` blocks merge** in Tailwind v4 — having one in `globals.css` and one in the imported `@sandra/tokens/theme.css` is fine; no conflict.
- **Vercel preview URL** for a PR is on the Vercel deployment page (`https://vercel.com/jarrad-5416s-projects/sandra/<deployment-id>`) → "Visit" button; not automatically in GitHub PR comments for this project.
