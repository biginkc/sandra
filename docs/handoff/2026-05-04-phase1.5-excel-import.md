## 9. Critical learnings

- **No dev server locally** — Jarrad's machine crashes when Next.js dev server starts. Use `npm run verify` for code checks, Vercel preview for UI checks. Never `npm run dev` or `next dev`.
- **Planner sub-agent must use Opus** — The GSD `planner_model` config controls the agent that writes PLAN.md. Never override it to Sonnet based on handoff suggestions. Memory updated to clarify this.
- **@sandra/tokens is a sibling repo** — `file:../Sandra Design System` in package.json. Not on npm. The sibling repo must exist at that relative path on the machine running `npm install`.
- **SearchInputPill has no X button** — X clear button must always stay in TableToolbarSearch's outer wrapper div; do not move inside SearchInputPill.
- **PR separation matters** — Excel import was initially committed onto the Phase 1.5 branch by mistake. Fixed by creating `feat/excel-import` from that commit and force-resetting the phase branch. Always open unrelated features on their own branch.
