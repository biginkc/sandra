## 9. Critical learnings
- **`@sandra/tokens` is a local file: reference** — never re-add it to `package.json`. The warm-paper tokens live inline in `globals.css` `:root {}` block. This will break Vercel every time.
- **Direct-to-main pushes are fine** — no branch protections on main; `npm run verify` runs via pre-commit hook.
- **`sms-composer.tsx` is a client component** — template fetch needs to either (a) be passed as a server prop from the detail page, or (b) fetched client-side on dialog open. Option (a) is cleaner (no client-side Supabase call needed).
- **Template rendering needs vars** — `loadTemplateVars()` is async and needs `propertyId + contactId`. These are already available in the detail page server component. Render server-side and pass rendered options to the composer, OR pass raw template body + let client substitute (simpler but skips token rendering).
