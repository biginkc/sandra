# Inbox metadata action UI

Clicking an action or dropping a selected group onto it calls the same preparation function. The server resolves eligibility and linked property scope before any acceptance. Supported UI entries are standalone assignment, outcome plus assignment, five ordinary outcomes, SMS opt-out, and clearing assignment. Assignment is property assignment; this does not schedule appointments. The Needs sequence outcome does not enroll or manage a sequence. SMS opt-out exposes canonical contact/linked-property/enrollment impact before acceptance. Permanent DNC and sending replies are outside this metadata slice.

The reviewed preparation binds typed targets, ordered steps and one idempotency key. The UI accepts only that preparation/key and then displays persisted per-target/per-step progress. It does not optimistically mutate outcomes or assignment. Hidden valid selections remain server-reviewed; unknown sender groups receive explicit exclusions in the initial metadata backend.

If acceptance is uncertain, the same pair is retained and new bulk actions are suspended. The narrowly approved sessionStorage record contains only opaque preparationId/idempotencyKey, under org/user/session/access-epoch identity. It contains no selection, labels, messages or other PII. A pending recovery response does not prove nonacceptance; retry uses the original pair. Only a completed durable receipt or serialized expired_not_accepted response removes the pair. Access loss removes private UI/cache state and suspends actions but retains this opaque pair so the exact same identity can recover after remount. Other identities never read it. Browser storage denial leaves in-memory idempotency intact and tells the user to keep the tab open until confirmed.

The action flag remains disabled in the user preview. Activation requires the reviewed public action RPCs and durable worker runtime, followed by actual application prepare/accept/status and restart verification. This source slice does not prove those deployment conditions.
