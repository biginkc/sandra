<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser/anon → Postgres | RLS gates encrypted columns. Anon and authenticated keys can SELECT a user's own row but the bytea blob is meaningless without the encryption key. |
| Vercel function → Postgres | Service-role calls upsert/get/delete RPCs with the encryption key passed as p_key arg. |
| OS env → Postgres function | OAUTH_TOKEN_ENCRYPTION_KEY crosses this boundary on every decrypt. |
| Logger / Sentry → tokens | OAuthSecret prevents accidental leakage. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-02-01 | Information Disclosure | user_oauth_tokens at rest | mitigate | pgcrypto pgp_sym_encrypt(text, key); key in Vercel env separate from DB credentials. |
| T-04-02-02 | Information Disclosure | logs/Sentry | mitigate | OAuthSecret wrapper class with non-enumerable _value + toJSON/toString returning "[REDACTED]". reportError extras restricted to non-token fields. Unit-tested. |
| T-04-02-03 | Elevation of Privilege | SECURITY DEFINER fns | mitigate | `set search_path = public, pg_temp` on all three SECURITY DEFINER functions; REVOKE from public + authenticated; GRANT to service_role only. |
