1cBehavior

Off by default. New reps see only the switch. Turning it on adds one compact dropdown line inside the same block; the selected script is what the coach loads at connect. With one script it is preselected.

Remembered. Stored per rep alongside the caller-ID choice (sandra.softphone.coach.v1: enabled + script id), so the switch stays where they left it across calls and reloads.

Covers one-click calls. The Call button on lead pages bypasses this popover, so it reads the same preference — no extra prompt on the fast path.

Reversible mid-call. With the coach off, the classic in-call popover keeps its existing “Open live coach” pill; opening it there flips the preference on for next time. Collapsing the coach does not flip it off.

Session still records. The coach session (transcript, phase) runs either way when the feature flag is on; the switch only governs whether the full-screen view opens at connect.

Hidden entirely when NEXT_PUBLIC_COACH_UI_ENABLED is unset.
